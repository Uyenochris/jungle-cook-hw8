# Jungle Cook - Homework 8

## About
This is my Jungle Cook website for N315. You can look at recipes and make your own.

## Website
https://in-info-web4.luddy.indianapolis.iu.edu/~cjuyeno/jungle-cook-hw8/

## GitHub

https://github.com/Uyenochris/jungle-cook-hw8

## What It Does
- Home and login pages
- Sign up and log in with Firebase
- Browse and view recipes
- Create, edit, and delete recipes
- See your own recipes
- Works on different screen sizes

## How It Works
I used HTML, CSS, and JavaScript.

Firebase is used for logging in. JSON is used for the recipes. Your own recipes are saved in the browser.

## How to Use
Open the website and click Browse to see recipes. Log in to make your own recipes.
